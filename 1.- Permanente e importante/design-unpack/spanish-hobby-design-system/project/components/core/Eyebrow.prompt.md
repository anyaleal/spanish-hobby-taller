**Eyebrow** — the small uppercase label above a section heading; the calm editorial cue that opens a section.

```jsx
<Eyebrow color="accent" rule>Real World Spanish</Eyebrow>
<h2>How it's spoken, mastered, lived</h2>
```

Colors: `accent` (orange, default) · `teal` · `brown` · `muted` · `onTeal` (for teal bands). Set `rule` for a short trailing line.
