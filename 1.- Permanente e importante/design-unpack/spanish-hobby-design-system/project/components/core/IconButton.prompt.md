**IconButton** — circular icon-only control for compact actions (social links, close, navigation, contact).

```jsx
<IconButton icon="fa-solid fa-envelope" label="Email us" variant="solid" />
<IconButton icon="fa-brands fa-instagram" label="Instagram" variant="outline" size="sm" />
```

Variants: `solid` (teal circle), `brown`, `accent` (orange), `outline`, `ghost`. Sizes `sm` · `md` · `lg`. Always pass `label`.
