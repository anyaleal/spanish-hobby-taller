**Logo** — the brand lockup (mark + "SpanishHobby" wordmark); use in headers, footers, covers.

```jsx
<Logo markSrc="../../assets/logo-mark.png" size="md" href="/" />
<Logo markSrc="../../assets/logo-mark.png" onDark />   {/* on teal bands */}
```

Sizes `sm` · `md` · `lg`. Set `onDark` for white-knockout treatment on teal. `showWord={false}` for the mark alone. Always set `markSrc` to the correct relative path for your page.
