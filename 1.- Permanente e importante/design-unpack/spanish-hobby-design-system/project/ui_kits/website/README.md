# Spanish Hobby — Website UI Kit

A high-fidelity, click-through recreation of the Spanish Hobby marketing site
(spanishhobby.com), built from the brand's components.

## Run it
Open `index.html`. It loads `../../_ds_bundle.js` (the compiled component
library) and Font Awesome, then mounts an interactive app with top-nav routing.

> The compiled bundle (`_ds_bundle.js`) is generated by the design-system
> compiler. If you open this file in a fresh checkout before the bundle exists,
> the page will be blank — view it from the Design System tab, or trigger a
> compile first.

## Screens
- **HomeScreen** — hero (teal→cream wash), feature trio, intro, the "100% free"
  teal band, and the "Latest — Lessons & Thoughts" article grid.
- **HiddenStructureScreen** — editorial prose + the alternating teal/brown topic
  stack (Phonetics, Phonology, Morphology, Syntax, Semantics).
- **BuildingBlocksScreen** — title + hero image, then a teal band of six
  part-of-speech article cards.
- **AboutScreen** — "Rooted in Language" prose, the bordered "Anya" bio card on
  teal, and the "Hola" image treatment.
- **Hero**, **Footer** — shared chrome.

## Composition
Screens compose the published components from the bundle (`NavBar`, `FeatureCard`,
`ArticleCard`, `SectionBand`, `Button`, `Logo`, `IconButton`) — they do not
re-implement primitives. Each screen file reads components from
`window.SpanishHobbyDesignSystem_99e317` and exposes itself on `window`. Image
paths come from `window.SH_ASSETS` (set in `index.html`).

## Notes
- Imagery uses on-brand abstract placeholders in `assets/img/` (teal/orange
  "hidden structure" art). Swap in real photography/illustration when available.
- Icons are Font Awesome Free 6 (a substitute for the legacy site's FA icons).
